# Simple-Board

## 간단한 커뮤니티 게시판

### 회원 기능
| 기능 | 접근 권한 | 설명 |
| --- | --- | --- |
| 회원가입 | 비회원&회원 | 아이디·비밀번호·이름·이메일·전화번호 입력 후 가입 단, 로그인 중 이용 불가 |
| 아이디 중복 확인 | 비회원&회원 | 가입 시 이미 사용 중인 아이디인지 확인 |
| 비밀번호 확인 | 비회원 | 가입 시 비밀번호를 두번 입력받아 제대로 입력 했는지 확인  |
| 로그인 | 비회원&회원 | 아이디·비밀번호 일치 확인 후 세션 생성 단, 로그인 중 이용 불가 |
| 아이디 기억 | 회원 | 아이디 기억 체크박스 클릭 후 로그인 (쿠키생성) |
| 로그아웃 | 회원 | 세션 삭제 후 게시판 목록으로 이동 |
| 마이페이지 | 회원 | 작성자가 작성한 글 목록 확인 |
| 회원 정보 수정 | 회원  | 마이페이지에서 아이디 제외 회원 정보 수정 |
| 회원탈퇴 | 회원 | 마이페이지에서 해당 사용자 삭제 |

### 게시판 기능(1)
| 기능 | 접근 권한  | 설명 |
| --- | --- | --- |
| 게시글 목록 조회 | 모두 | 10개씩 페이지 나누기 |
| 게시글 검색 | 모두 | 검색란에 제목 또는 작성자 명 검색 |
| 게시글 상세 조회 | 모두 | 내용확인, 열람할 때마다 조회수 +1 |
| 게시글 작성 | 회원 | 제목·내용 입력 후 등록 |
| 게시글 수정 | 작성자 | 본인이 작성한 글만 수정 가능 |
| 게시글 삭제
 | 작성자 | 본인이 작성한 글만 삭제 가능
(달린 댓글도 함께 삭제) |

### 게시판 기능(2)
| 게시판 공간 | 접근 권한 | 설명 |
| --- | --- | --- |
| 가입인사 게시판 | New, Normal | 처음 가입시 작성 가능한 공간 |
| 자유게시판 | Normal | 가입인사 게시판에 글 작성후 이용 가능 |
| 질문게시판 | Normal | 가입인사 게시판에 글 작성후 이용 가능 |


### 댓글 기능
| 기능 | 접근 권한 | 설명 |
| --- | --- | --- |
| 댓글 목록 조회 | **모두** | 상세보기 화면에서 오래된 순으로 표시 |
| 댓글 작성 | 회원 | 페이지 새로고침 없이 등록 (AJAX) |
| 댓글 삭제 | **작성자** | 본인 댓글만 삭제, 페이지 새로고침 없이 제거 (AJAX) |
